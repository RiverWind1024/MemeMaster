# S3 同步 v2 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用单一权威格式（manifest 索引 + 单条文件 + 内容寻址图片）替换现有的双格式 S3 同步，支持多设备双向 LWW 同步，并把同步逻辑与具体对象存储解耦以便测试。

**Architecture:** 抽出 `ObjectStore` 接口封装对象存储（生产用 Minio，测试用内存实现）；新增 `SyncEngine` 承载三阶段（推送/拉取/收敛）LWW 算法，只依赖 `ObjectStore` + 各 Repository；`S3SyncService` 退化为配置/流式进度/统计的薄封装。manifest 作为权威索引，meme json 内联 tags/colors/albumIds，图片按 sha256 内容寻址。

**Tech Stack:** Dart / Flutter、drift（SQLite）、minio(Dart)、riverpod、flutter gen-l10n。

**Spec:** `docs/superpowers/specs/2026-10-10-s3-sync-v2-design.md`

## Global Constraints

- 同步范围：图片、meme 元数据、标签/颜色、相册与归属、用户统计；**不含 embedding**。
- 冲突策略：纯 LWW（`updatedAt` 大者赢，平局保持本地不动）。
- 触发方式：**仅手动**；不做后台/定时/自动。
- 平台：Android / Linux / macOS / Windows，纯 Dart 逻辑不得依赖 Flutter 插件（CLI 可用）。
- 旧格式（`snapshot-v1.json`、`data/*`、`memes/*`）**不再读取**；迁移在数据层一次性完成。
- 数据库 schema 从 v6 升到 v7（album 增加 `updatedAt` 列）。
- 所有新增/修改的代码注释用中文；提交信息遵循仓库现有风格（`feat:` / `fix:` / `docs:` / `test:`）。
- 测试运行：`flutter test`（CI 的 analyze job 已跑）。纯 Dart 单测放在 `test/services/`。

// lib/services/object_store.dart
import 'dart:io';
import 'dart:typed_data';
import 'package:minio/minio.dart';

/// 对象存储抽象：把 S3 操作与同步逻辑解耦，便于单测（内存实现）。
abstract class ObjectStore {
  /// 读取字节；不存在返回 null。
  Future<Uint8List?> getBytes(String key);

  /// 写入字节。
  Future<void> putBytes(String key, Uint8List bytes);

  /// 上传本地文件。
  Future<void> uploadFile(String key, String srcPath);

  /// 下载到本地文件。
  Future<void> downloadToFile(String key, String destPath);

  /// key 是否存在。
  Future<bool> exists(String key);

  /// 列出指定前缀下的所有 key。
  Future<List<String>> list(String prefix);

  /// 删除 key（不存在时忽略）。
  Future<void> delete(String key);
}

/// 内存实现，仅用于测试。
class InMemoryObjectStore implements ObjectStore {
  final Map<String, Uint8List> _data = {};

  @override
  Future<Uint8List?> getBytes(String key) async => _data[key];

  @override
  Future<void> putBytes(String key, Uint8List bytes) async {
    _data[key] = Uint8List.fromList(bytes);
  }

  @override
  Future<void> uploadFile(String key, String srcPath) async {
    _data[key] = await File(srcPath).readAsBytes();
  }

  @override
  Future<void> downloadToFile(String key, String destPath) async {
    final bytes = _data[key];
    if (bytes == null) throw FileSystemException('not found', key);
    await File(destPath).writeAsBytes(bytes);
  }

  @override
  Future<bool> exists(String key) async => _data.containsKey(key);

  @override
  Future<List<String>> list(String prefix) async =>
      _data.keys.where((k) => k.startsWith(prefix)).toList();

  @override
  Future<void> delete(String key) async {
    _data.remove(key);
  }
}

/// 基于 minio 的实现。传入 client 工厂以便复用/懒加载。
class MinioObjectStore implements ObjectStore {
  final Minio Function() _client;
  final String bucket;

  MinioObjectStore({required Minio Function() client, required this.bucket})
      : _client = client;

  @override
  Future<Uint8List?> getBytes(String key) async {
    try {
      final stream = await _client().getObject(bucket, key);
      final builder = BytesBuilder();
      await for (final chunk in stream) {
        builder.add(chunk);
      }
      return builder.takeBytes();
    } on MinioS3Error {
      return null;
    }
  }

  @override
  Future<void> putBytes(String key, Uint8List bytes) async {
    await _client().putObject(bucket, key, Stream.value(bytes),
        size: bytes.length);
  }

  @override
  Future<void> uploadFile(String key, String srcPath) async {
    await _client().fPutObject(bucket, key, srcPath);
  }

  @override
  Future<void> downloadToFile(String key, String destPath) async {
    final stream = await _client().getObject(bucket, key);
    await stream.pipe(File(destPath).openWrite());
  }

  @override
  Future<bool> exists(String key) async {
    try {
      await _client().statObject(bucket, key);
      return true;
    } on MinioS3Error {
      return false;
    }
  }

  @override
  Future<List<String>> list(String prefix) async {
    final result = <String>[];
    final stream = _client().listObjects(bucket, prefix: prefix, recursive: true);
    await for (final batch in stream) {
      for (final obj in batch.objects) {
        if (obj.key != null) result.add(obj.key!);
      }
    }
    return result;
  }

  @override
  Future<void> delete(String key) async {
    try {
      await _client().removeObject(bucket, key);
    } on MinioS3Error {
      // 忽略不存在
    }
  }
}
```

// lib/services/s3_manifest.dart

/// manifest 中单个实体的索引信息。
class ManifestEntry {
  final int updatedAt;
  final int? deletedAt;
  final String? hash; // 仅 meme：图片内容哈希
  final String? ext;  // 仅 meme：图片扩展名（含点）

  const ManifestEntry({
    required this.updatedAt,
    this.deletedAt,
    this.hash,
    this.ext,
  });

  Map<String, dynamic> toJson() => {
        'updatedAt': updatedAt,
        if (deletedAt != null) 'deletedAt': deletedAt,
        if (hash != null) 'hash': hash,
        if (ext != null) 'ext': ext,
      };

  factory ManifestEntry.fromJson(Map<String, dynamic> j) => ManifestEntry(
        updatedAt: j['updatedAt'] as int,
        deletedAt: j['deletedAt'] as int?,
        hash: j['hash'] as String?,
        ext: j['ext'] as String?,
      );
}

/// 权威索引：一次 GET 即可算出全部差异。
class Manifest {
  static const currentSchema = 2;

  final int schema;
  final int generatedAt;
  final String lastWriter;
  final int clock;
  final Map<String, ManifestEntry> memes;
  final Map<String, ManifestEntry> albums;
  final int? userStatsUpdatedAt;

  const Manifest({
    required this.schema,
    required this.generatedAt,
    required this.lastWriter,
    required this.clock,
    required this.memes,
    required this.albums,
    this.userStatsUpdatedAt,
  });

  factory Manifest.empty() => const Manifest(
        schema: currentSchema,
        generatedAt: 0,
        lastWriter: '',
        clock: 0,
        memes: {},
        albums: {},
      );

  int maxUpdatedAt() {
    var max = 0;
    for (final e in memes.values) {
      if (e.updatedAt > max) max = e.updatedAt;
    }
    for (final e in albums.values) {
      if (e.updatedAt > max) max = e.updatedAt;
    }
    if ((userStatsUpdatedAt ?? 0) > max) max = userStatsUpdatedAt!;
    return max;
  }

  Map<String, dynamic> toJson() => {
        'schema': schema,
        'generatedAt': generatedAt,
        'lastWriter': lastWriter,
        'clock': clock,
        'memes': memes.map((k, v) => MapEntry(k, v.toJson())),
        'albums': albums.map((k, v) => MapEntry(k, v.toJson())),
        if (userStatsUpdatedAt != null) 'userStatsUpdatedAt': userStatsUpdatedAt,
      };

  factory Manifest.fromJson(Map<String, dynamic> j) => Manifest(
        schema: j['schema'] as int? ?? 1,
        generatedAt: j['generatedAt'] as int? ?? 0,
        lastWriter: j['lastWriter'] as String? ?? '',
        clock: j['clock'] as int? ?? 0,
        memes: ((j['memes'] as Map?) ?? {})
            .map((k, v) => MapEntry(k as String, ManifestEntry.fromJson(v as Map<String, dynamic>))),
        albums: ((j['albums'] as Map?) ?? {})
            .map((k, v) => MapEntry(k as String, ManifestEntry.fromJson(v as Map<String, dynamic>))),
        userStatsUpdatedAt: j['userStatsUpdatedAt'] as int?,
      );
}
```

```dart
// lib/services/s3_sync_engine.dart
import 'dart:convert';
import 'dart:io';
import 'dart:typed_data';

import '../core/database/database.dart';
import '../core/repositories/album_repository.dart';
import '../core/repositories/meme_repository.dart';
import 'object_store.dart';
import 's3_manifest.dart';
import 's3_secret_store.dart';
import 's3_sync_serializer.dart';

const _manifestKey = 'sync/manifest.json';
const _clockKey = 'sync_clock';
const _deviceIdKey = 'device_id';

class SyncResult {
  int pushed = 0;
  int pulled = 0;
  int deleted = 0;
  int imagesUploaded = 0;
  int imagesDownloaded = 0;
  int failed = 0;
}

class SyncEngine {
  final ObjectStore _store;
  final MemeRepository _memeRepo;
  final AlbumRepository _albumRepo;
  final AppDatabase _db;
  final SyncStateDao _syncStateDao;
  final S3SecretStore _secretStore;

  SyncEngine({
    required ObjectStore store,
    required MemeRepository memeRepo,
    required AlbumRepository albumRepo,
    required AppDatabase db,
    required SyncStateDao syncStateDao,
    required S3SecretStore secretStore,
  })  : _store = store,
        _memeRepo = memeRepo,
        _albumRepo = albumRepo,
        _db = db,
        _syncStateDao = syncStateDao,
        _secretStore = secretStore;

  Future<String> _deviceId() async {
    var id = await _secretStore.read(_deviceIdKey);
    if (id == null || id.isEmpty) {
      id = 'dev-${DateTime.now().microsecondsSinceEpoch}';
      await _secretStore.write(_deviceIdKey, id);
    }
    return id;
  }

  Future<Manifest> _loadManifest() async {
    final bytes = await _store.getBytes(_manifestKey);
    if (bytes == null) return Manifest.empty();
    return Manifest.fromJson(jsonDecode(utf8.decode(bytes)) as Map<String, dynamic>);
  }

  String blobKey(String hash) => 'blobs/$hash';

  /// 执行一次双向同步（三阶段）。
  Future<SyncResult> sync() async {
    final result = SyncResult();
    final remote = await _loadManifest();
    final deviceId = await _deviceId();

    // 逻辑时钟：不小于已知最大 updatedAt
    var clock = remote.maxUpdatedAt();
    final localClockStr = await _syncStateDao.get(_clockKey);
    final localClock = int.tryParse(localClockStr ?? '') ?? 0;
    if (localClock > clock) clock = localClock;

    final newManifest = Manifest(
      schema: Manifest.currentSchema,
      generatedAt: DateTime.now().millisecondsSinceEpoch,
      lastWriter: deviceId,
      clock: clock,
      memes: Map.of(remote.memes),
      albums: Map.of(remote.albums),
      userStatsUpdatedAt: remote.userStatsUpdatedAt,
    );

    // ---- 阶段 1：推送本地变更 ----
    final localMemes = await _db.memeDao.getAllIncludingDeleted();
    for (final meme in localMemes) {
      try {
        final remoteEntry = remote.memes[meme.id];
        final isChanged = remoteEntry == null || meme.updatedAt > remoteEntry.updatedAt;
        if (!isChanged) continue;
        // 逻辑时钟兜底：确保推送时间戳大于已知远端时钟
        final stamp = meme.updatedAt > clock ? meme.updatedAt : clock + 1;
        if (meme.deletedAt != null) {
          await _store.putBytes('sync/memes/${meme.id}.json',
              _encode(_tombstoneJson(meme, stamp)));
          newManifest.memes[meme.id] =
              ManifestEntry(updatedAt: stamp, deletedAt: meme.deletedAt, hash: meme.fileHash, ext: _ext(meme.filePath));
          result.pushed++;
          continue;
        }
        final data = await _buildMemeData(meme);
        await _store.putBytes('sync/memes/${meme.id}.json', _encode(data.toJson()));
        if (!await _store.exists(blobKey(meme.fileHash))) {
          final file = await _storageGetImage(meme.filePath);
          if (await file.exists()) {
            await _store.uploadFile(blobKey(meme.fileHash), file.absolute.path);
            result.imagesUploaded++;
          }
        }
        newManifest.memes[meme.id] =
            ManifestEntry(updatedAt: stamp, hash: meme.fileHash, ext: _ext(meme.filePath));
        result.pushed++;
      } catch (_) {
        result.failed++;
      }
    }

    // 相册推送
    final localAlbums = await _albumRepo.getAll();
    for (final album in localAlbums) {
      final remoteEntry = remote.albums[album.id];
      final rev = album.updatedAt > 0 ? album.updatedAt : album.createdAt;
      if (remoteEntry == null || rev > remoteEntry.updatedAt) {
        final stamp = rev > clock ? rev : clock + 1;
        await _store.putBytes('sync/albums/${album.id}.json', _encode(_albumJson(album)));
        newManifest.albums[album.id] = ManifestEntry(updatedAt: stamp);
        result.pushed++;
      }
    }

    // ---- 阶段 2：拉取远端变更 ----
    for (final entry in remote.memes.entries) {
      try {
        final id = entry.key;
        final remoteEntry = entry.value;
        final local = await _db.memeDao.getByIdIncludingDeleted(id);
        final localUpdated = local?.updatedAt ?? -1;
        if (local != null && localUpdated >= remoteEntry.updatedAt) continue;

        if (remoteEntry.deletedAt != null) {
          if (local != null && local.deletedAt == null) {
            await _db.memeDao.softDeleteWithTimestamp(id, remoteEntry.deletedAt!);
            result.deleted++;
          }
          newManifest.memes[id] = ManifestEntry(
              updatedAt: remoteEntry.updatedAt, deletedAt: remoteEntry.deletedAt,
              hash: remoteEntry.hash, ext: remoteEntry.ext);
          continue;
        }

        final bytes = await _store.getBytes('sync/memes/$id.json');
        if (bytes == null) { result.failed++; continue; }
        final data = MemeSyncData.fromJson(jsonDecode(utf8.decode(bytes)) as Map<String, dynamic>);
        await _applyMeme(data);
        if (data.meme.fileHash.isNotEmpty && !await _store.exists(blobKey(data.meme.fileHash))) {
          // 远端无图，跳过
        } else if (data.meme.fileHash.isNotEmpty) {
          final file = await _storageGetImage(data.meme.filePath);
          if (!await file.exists()) {
            await file.parent.create(recursive: true);
            await _store.downloadToFile(blobKey(data.meme.fileHash), file.absolute.path);
            result.imagesDownloaded++;
          }
        }
        newManifest.memes[id] = ManifestEntry(
            updatedAt: remoteEntry.updatedAt, hash: remoteEntry.hash, ext: remoteEntry.ext);
        result.pulled++;
      } catch (_) {
        result.failed++;
      }
    }

    // 相册拉取
    for (final entry in remote.albums.entries) {
      final local = await _albumRepo.getById(entry.key);
      if (local != null && local.updatedAt >= entry.value.updatedAt) continue;
      final bytes = await _store.getBytes('sync/albums/${entry.key}.json');
      if (bytes == null) continue;
      await _applyAlbum(jsonDecode(utf8.decode(bytes)) as Map<String, dynamic>);
      newManifest.albums[entry.key] = entry.value;
      result.pulled++;
    }

    // ---- 阶段 3：收敛 ----
    newManifest = Manifest( // 见下方修正：Manifest 字段 final，需重建
      schema: newManifest.schema, generatedAt: DateTime.now().millisecondsSinceEpoch,
      lastWriter: deviceId, clock: clock, memes: newManifest.memes,
      albums: newManifest.albums, userStatsUpdatedAt: newManifest.userStatsUpdatedAt);
    await _store.putBytes(_manifestKey, _encode(newManifest.toJson()));
    await _syncStateDao.set(_clockKey, clock.toString());
    await _syncStateDao.setLastSyncAt(DateTime.now().millisecondsSinceEpoch);
    return result;
  }

  // ---- 辅助 ----

  Future<MemeSyncData> _buildMemeData(Meme meme) async {
    final tags = await _memeRepo.getTags(meme.id);
    final colors = await _memeRepo.getColors(meme.id);
    final albumIds = await _albumRepo.getAlbumIdsByMeme(meme.id);
    return MemeSyncData(meme: meme, tags: tags, colors: colors, albumIds: albumIds);
  }

  Future<void> _applyMeme(MemeSyncData data) async {
    await _db.transaction(() async {
      await _db.into(_db.memesTable).insertOnConflictUpdate(data.meme);
      await (_db.delete(_db.tagsTable)..where((t) => t.memeId.equals(data.meme.id))).go();
      await (_db.delete(_db.colorsTable)..where((t) => t.memeId.equals(data.meme.id))).go();
      await (_db.delete(_db.memeAlbumsTable)..where((t) => t.memeId.equals(data.meme.id))).go();
      for (final t in data.tags) {
        await _db.into(_db.tagsTable).insertOnConflictUpdate(t);
      }
      for (final c in data.colors) {
        await _db.into(_db.colorsTable).insertOnConflictUpdate(c);
      }
      final now = DateTime.now().millisecondsSinceEpoch;
      for (final albumId in data.albumIds) {
        await _db.into(_db.memeAlbumsTable).insertOnConflictUpdate(
            MemeAlbum(memeId: data.meme.id, albumId: albumId, addedAt: now));
      }
    });
  }

  Future<void> _applyAlbum(Map<String, dynamic> j) async {
    await _db.into(_db.albumsTable).insertOnConflictUpdate(Album(
          id: j['id'] as String, name: j['name'] as String,
          icon: j['icon'] as String?, sortOrder: j['sortOrder'] as int,
          isDefault: j['isDefault'] as int, createdAt: j['createdAt'] as int,
          updatedAt: j['updatedAt'] as int? ?? 0));
  }

  Map<String, dynamic> _albumJson(Album a) => {
        'id': a.id, 'name': a.name, 'icon': a.icon, 'sortOrder': a.sortOrder,
        'isDefault': a.isDefault, 'createdAt': a.createdAt, 'updatedAt': a.updatedAt,
      };

  Map<String, dynamic> _tombstoneJson(Meme m, int stamp) =>
      {'id': m.id, 'updatedAt': stamp, 'deletedAt': m.deletedAt, 'fileHash': m.fileHash};

  Uint8List _encode(Map<String, dynamic> j) =>
      Uint8List.fromList(utf8.encode(jsonEncode(j)));

  String _ext(String path) {
    final dot = path.lastIndexOf('.');
    return dot >= 0 ? path.substring(dot) : '';
  }

  Future<File> _storageGetImage(String relPath) async {
    // 复用 FileStorageService 的规则：basePath/relPath
    return File('${await _basePath()}/$relPath');
  }

  Future<String> _basePath() async {
    // 由构造注入的存储服务提供；在 service 层设置
    return _basePathOverride!;
  }

  String? _basePathOverride;
  set basePath(String v) => _basePathOverride = v;
}
```

> **实现提示（重要）**：上面 `_storageGetImage` 用 `_basePathOverride` 是简化写法。更干净的做法是给 `SyncEngine` 构造注入 `FileStorageService storage`，直接用 `storage.getImage(relPath)`。请在实现时改成注入 `FileStorageService`，并删除 `_basePathOverride`。此外 `manifest.memes/albums` 需可变：把 `Manifest` 的 `memes`/`albums` 字段类型保持 `Map`，但阶段 3 直接对 `newManifest` 的同一 Map 实例复用即可，无需重建 `Manifest`（若字段为 final 引用，其内容可变）。请在实现中让阶段 1/2 直接修改 `newManifest.memes`/`newManifest.albums`，阶段 3 直接 `putBytes(_manifestKey, ...)`。

- [ ] **Step 2: 重写 `incremental()`**

```dart
  Stream<S3SyncProgress> incremental() async* {
    if (!isConfigured) {
      yield const S3SyncProgress(status: S3SyncStatus.error, errorMessage: 'S3 未配置');
      return;
    }
    yield const S3SyncProgress(status: S3SyncStatus.uploading, completed: 0, total: 1);
    try {
      final r = await _engine.sync();
      yield S3SyncProgress(
        status: S3SyncStatus.idle, completed: 1, total: 1,
        errorMessage: '完成：推送 ${r.pushed} / 拉取 ${r.pulled} / 删除 ${r.deleted} / '
            '上传图片 ${r.imagesUploaded} / 失败 ${r.failed}',
      );
    } catch (e) {
      yield S3SyncProgress(status: S3SyncStatus.error, errorMessage: '同步失败: $e');
    }
  }
```

实现：`list('')` 全部对象 → `list('blobs/')` 得 blob 集；加载 `sync/manifest.json` 得被引用 hash 集；`orphanImages = blobs - referenced`；`metaFiles = 非 blob 对象数`；`totalBytes` 需要 list 带 size —— 给 `ObjectStore` 增加 `Future<List<ObjectInfo>> listWithSize(String prefix)` 或让 `MinioObjectStore.list` 返回 key（size 另计）。**实现选择**：给接口增加 `Future<Map<String,int>> listWithSizes(String prefix)`，`InMemoryObjectStore` 返回字节长度，`MinioObjectStore` 用 `obj.size`。

- [ ] **Step 4: `cleanupOrphans()`**

```dart
  /// 删除未被 manifest 引用的 blobs 与遗留旧 key。
  Future<int> cleanupOrphans() async {
    final manifest = await _loadManifestForCleanup();
    final referenced = manifest.memes.values.where((e) => e.hash != null).map((e) => e.hash!).toSet();
    var removed = 0;
    for (final key in await _store.list('blobs/')) {
      final hash = key.substring('blobs/'.length);
      if (!referenced.contains(hash)) { await _store.delete(key); removed++; }
    }
    for (final legacy in ['snapshot-v1.json', 'data/memes.json', 'data/albums.json']) {
      if (await _store.exists(legacy)) { await _store.delete(legacy); removed++; }
    }
    for (final key in await _store.list('data/memes/')) { await _store.delete(key); removed++; }
    for (final key in await _store.list('memes/')) { await _store.delete(key); removed++; }
    return removed;
  }
```
